# DMR 监控台使用说明

页面只显示服务保存的真实通联记录。桌面同时显示 TS1 和 TS2，各自独立滚动；手机通过时隙标签切换。站点名称、接收地址、TG 和来源取自服务配置。

## 监听控制

工具栏的「开始监听 / 停止监听」控制接收与文字处理，网页和历史录音始终可用。首次部署没有保存的选择时，监听保持停止；用户的开始或停止选择在服务重启后保留。启动或停止正在进行时，控制按钮禁用，状态由服务实时更新。

需要控制凭据的站点会显示密码输入弹窗。凭据只保留在当前页面的内存中，不写入本地存储。重新加载页面后，需要控制时再次输入。接收地址未配置、权限不符或连接断开时，页面显示具体的操作错误。

## 连接设置

「连接设置」填写设备主机名或IP、SSH端口、用户名和密钥/密码认证方式。首次没有连接配置时自动打开；测试和保存都要求监听已停止。保存不会自动开始监听。

SSH口令只写入服务端，页面不读取已保存的口令。同一地址、端口和用户名可留空保留；更改目标必须重新输入。保存或关闭后清空输入，控制凭据仍只保留在当前页面内存。

未知设备先显示算法和指纹。通过设备或管理员核对后，勾选「信任此设备」再测试或保存；指纹请求本身不会保存设置。连接测试失败或需要信任时，页面不会提示保存成功。

「测试连接」仅验证 SSH、Python、免密 sudo 和采集所需的原始套接字权限，不开始持续监听。密钥登录使用部署时提供的身份密钥；密码登录无需先配置 SSH 免密。

## 翻译设置

停止监听后，可在「翻译设置」配置 API 接口地址、模型、Responses 或 Chat Completions 模式，以及是否启用翻译。保存不会自动开始监听。关闭翻译后仍可录音、回放和转录。

API 密钥只写入服务端，页面只显示是否已配置。同一接口地址可留空保留已保存的密钥，更换模型或 API 模式也可保留。更换提供方后启用翻译需要新密钥；禁用翻译时可清除旧密钥。主动清除已有密钥前也需先禁用翻译。保存或关闭后清空本次密钥输入，不写入浏览器本地存储。

网页保存的翻译配置在服务重启和容器重建后保留，并优先于部署时的初始默认值。完整数据备份包含已保存的私密凭据，应由操作员妥善保管。

## 通联日志

每条记录先显示时间、呼号和 DMR ID、方向、TG、时长与处理状态。`NET` 表示网络下行，`RX` 表示本地射频上行；没有记录方向的历史通话显示 `—`。按通话行可折叠或展开内容，键盘 Enter / Space 同样有效。

原文和中文默认显示，可在工具栏分别关闭。原文标注「自动转写」，译文标注「自动翻译」，内容摘要默认折叠并标注「自动生成」。这些文字处理结果不会替代录音。

搜索匹配呼号、DMR ID、TG、国家、方向、原文、译文和摘要。筛选可选择已有文字、处理中或处理失败。不足一秒的已结束通话及服务判定为短通话、丢弃的记录不显示。

## 追踪和回放

「暂停追踪」暂停自动滚动，接收与记录继续进行。向上浏览历史时，当前时隙也会暂停自动滚动。新的通话按唯一记录计数，同一通话的识别或翻译更新不重复计数；「N 条新通话 / 跳到最新」回到底部。「恢复追踪」重新跟随最新记录。

工具栏的追踪选择保存在当前浏览器：暂停后刷新仍保持暂停，恢复后刷新仍保持追踪。未保存选择的浏览器默认追踪；其他浏览器分别保存自己的选择。

「回放」按钮可用键盘激活；播放后可用进度条和方向键定位。一次只播放一条录音。停止监听后仍可回放历史录音。

## 链路状态

状态栏分别显示实时更新、设备接收、识别、翻译及等待数量。宽屏右侧诊断栏提供最近报文和队列信息；其他尺寸可打开「链路详情」。实时更新连接断开时显示恢复提示，保留当前记录；恢复后同步最新快照。手动「刷新」可重新同步状态和近期记录。

浅色和深色切换只影响显示。主题选择保存在当前浏览器，不包含控制凭据。
